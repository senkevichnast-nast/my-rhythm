# Мой ритм

Личный планер: https://senkevichnast-nast.github.io/my-rhythm/

Главная, неделя, привычки, английский, блог, здоровье и личные проекты. Один `index.html` с встроенными стилями, JavaScript, шрифтом Manrope и иллюстрацией попугайчика Семечки.

## Использование

На опубликованном сайте: ввести свою почту и подтвердить вход в том браузере, где планируется пользоваться кабинетом. Встроенный браузер почты и Яндекс хранят разные сессии. Скопировать адрес кнопки входа из письма и вставить в поле «Ссылка входа из письма» в планере, не открывая ссылку. Подтверждение сохранится в текущем браузере. Предусмотрен и ввод кода, если позже будет подключён собственный отправитель писем. Для одной учётной записи на всех устройствах использовать одну и ту же почту.

Вход сохраняется после перезагрузки и повторного открытия браузера. Новый браузер, явный выход, удаление данных сайта или отзыв сессии сервисом требуют подтверждения. Временные сетевые ошибки не удаляют сессию; при наличии локальной копии кабинет открывается без сети, затем возобновляет синхронизацию.

Данные хранятся в Supabase с разграничением по владельцу и локальной копией браузера. Изменения отправляются автоматически; другие устройства получают обновления при открытии и примерно каждые 12 секунд, пока страница открыта. В конфликте одной записи показывается выбор версий. Таймер работает отдельно на каждом устройстве; сохранённые минуты синхронизируются.

Локальный файл открывается двойным щелчком и работает без регистрации. Его данные отдельны от опубликованного сайта. Перенос: «Экспорт» в локальной версии → «Импорт» в опубликованной после входа. Импорт заменяет текущие записи и требует подтверждения в интерфейсе.

## Публикация и хранение

Самочувствие отмечается трижды в день: 00:00–11:00, 11:01–17:00 и 17:01–24:00 по местному времени устройства. После «Сохранить отметку» карточка скрывается до следующего периода. Вечерняя карточка включает итог дня. История, редактирование и средние оценки доступны в «Здоровье → История и оценки» за всё время, 30 или 7 дней.

Подробный опрос в «Здоровье → На сегодня» сохраняется кнопкой «Сохранить запись». Дату можно менять, прошлые записи открываются через «История».

На главной постоянно доступна карточка «Здоровье сегодня». В здоровье есть заметные переходы к опросу, истории оценок, тренировкам, меню и покупкам, циклу и симптомам. Меню предлагается из собственных рецептов и заполняет только пустые приёмы пищи. Календарь цикла, длина завершённых циклов и повторения симптомов строятся по введённым датам. Импорт данных из Flo автоматически не выполняется — предыдущие даты можно внести вручную.

Недельный план использует те же задачи, публикации и тренировки, что главная и календарь. Сегодняшняя колонка закреплена при прокрутке.

- GitHub Pages: ветка `main`, корень репозитория.
- `schema.sql`: таблица, правило чтения собственных записей и транзакционная функция сохранения с проверкой версии.
- Формат данных `schemaVersion: 2` сохраняет отметки по периодам. Функция сохранения не разрешает старой открытой версии сайта перезаписать новые поля: такую вкладку нужно обновить.
- В HTML находится только публичный publishable key. Ключ не даёт доступ к дневникам без пользовательского входа. Секретные ключи и записи дневника не публикуются в репозитории.
- Supabase Site URL настроен на опубликованный адрес. Используется стандартное письмо со ссылкой входа, без своего SMTP. Стандартная отправка ограничена адресами участников проекта и лимитами провайдера; для личного использования владельцем.
- На текущем бесплатном тарифе Supabase редактирование шаблонов требует собственного SMTP (либо тарифа Pro); это подтверждено в панели 22.11.2026. Платные услуги не включены. После подключения отправителя для писем с кодом применить `cloud/email-code-template.html` в шаблонах Authentication → Email → Magic Link и Confirm signup. Это отдельная настройка Supabase; загрузка HTML в GitHub не меняет шаблон писем. Текущая проверка пароля не используется, код подтверждается штатным Auth API. Резервный ввод ссылки принимает только HTTPS-ссылки входа своего проекта и не переходит по вставленному адресу.
- Бесплатный проект Supabase может приостанавливаться при длительном отсутствии активности. Возобновить его можно в Supabase Dashboard. Резервную копию дневника можно скачать кнопкой «Экспорт».

## Проверка

`node verify.cjs` проверяет форматы данных, импорт, даты, недельную нумерацию, таймер, циклы, группировку плана, новые поля здоровья и объединение изменений.

`node tests/auth-session.cjs` проверяет восстановление входа, повторное открытие, сетевые сбои, обновление токенов между вкладками, ввод кода и допустимость ссылок подтверждения.
