# Мой ритм

Личный планер: https://senkevichnast-nast.github.io/my-rhythm/

Главная, неделя, привычки, английский, блог, здоровье и личные проекты. Один `index.html` с встроенными стилями, JavaScript, шрифтом Manrope и иллюстрацией попугайчика Семечки.

## Использование

На опубликованном сайте: ввести свою почту, открыть ссылку из письма на том же устройстве. Вход сохраняется в браузере; повторное подтверждение требуется на новом устройстве, после выхода или очистки браузера. Для одной учётной записи на всех устройствах использовать одну и ту же почту.

Данные хранятся в Supabase с разграничением по владельцу и локальной копией браузера. Изменения отправляются автоматически; другие устройства получают обновления при открытии и примерно каждые 12 секунд, пока страница открыта. В конфликте одной записи показывается выбор версий. Таймер работает отдельно на каждом устройстве; сохранённые минуты синхронизируются.

Локальный файл открывается двойным щелчком и работает без регистрации. Его данные отдельны от опубликованного сайта. Перенос: «Экспорт» в локальной версии → «Импорт» в опубликованной после входа. Импорт заменяет текущие записи и требует подтверждения в интерфейсе.

## Публикация и хранение

- GitHub Pages: ветка `main`, корень репозитория.
- `schema.sql`: таблица, правило чтения собственных записей и транзакционная функция сохранения с проверкой версии.
- В HTML находится только публичный publishable key. Ключ не даёт доступ к дневникам без пользовательского входа. Секретные ключи и записи дневника не публикуются в репозитории.
- Supabase Site URL настроен на опубликованный адрес. Используется стандартное письмо со ссылкой входа, без своего SMTP. Стандартная отправка ограничена адресами участников проекта и лимитами провайдера; для личного использования владельцем.
- Бесплатный проект Supabase может приостанавливаться при длительном отсутствии активности. Возобновить его можно в Supabase Dashboard. Резервную копию дневника можно скачать кнопкой «Экспорт».

## Проверка

`node verify.cjs` проверяет форматы данных, импорт, даты, недельную нумерацию, таймер, циклы, группировку плана, новые поля здоровья и объединение изменений.
